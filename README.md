# Steam Market Monitor

![Chrome Extension](https://img.shields.io/badge/Chrome%20Extension-v18.0-blue)
![MIT License](https://img.shields.io/badge/License-MIT-green)

Расширение для Chrome/Яндекс.Браузера для мониторинга цен предметов на торговой площадке Steam.  
Разработано: **GFL25**

---

## 🔍 Описание

Это расширение позволяет отслеживать цены на предметы в Steam Market с индивидуальными триггерами:

- Проверка ↓ «цена ниже»
- Проверка ↑ «цена выше»
- Рандомный интервал между проверками
- Системные уведомления, когда условия выполняются
- Автоматическое открытие страницы предмета при срабатывании
- Подсветка предметов при приближении к триггеру
- Статус работы мониторинга

---

## 🧩 Возможности

| Функция | Описание |
|---------|----------|
| Несколько предметов | Отслеживание нескольких предметов одновременно |
| Черновик формы | Сохраняет введённые поля даже при закрытии popup |
| Настройки интервала | Настройка min/max и шанс минимального интервала |
| Стабильный таймер | Проверки через `chrome.alarms`, не зависает |
| Нотификации | Уведомления при достижении триггеров |

---

## 🛠 Установка

1. Скачайте или клонируйте репозиторий
2. Откройте в браузере страницу: `chrome://extensions`
3. Включите **Режим разработчика**
4. Нажмите **Загрузить распакованное расширение**
5. Выберите папку проекта
