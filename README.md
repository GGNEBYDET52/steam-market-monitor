# Steam Monitor

Мониторинг цен предметов Steam Market с индивидуальными триггерами и рандомным интервалом проверки.

Разработано: GFL25

---

## Возможности

- Мониторинг нескольких предметов
- Индивидуальные триггеры:
  - Цена ниже
  - Цена выше
- Проверка через случайный интервал
- Системные уведомления при срабатывании
- Автоматическое открытие вкладки
- Подсветка при приближении к триггеру
- Сохранение данных через chrome.storage

---

## Как установить

1. Скачать проект
2. Открыть `browser://extensions`
3. Включить режим разработчика
4. Нажать "Загрузить распакованное расширение"
5. Выбрать папку проекта

---

## Как использовать

1. Перейти во вкладку "Добавить"
2. Вставить ссылку на предмет Steam Market
3. Указать триггеры цены
4. Сохранить интервал проверки
5. Мониторинг запускается автоматически

---

## Техническая реализация

- Manifest V3
- Service Worker
- chrome.alarms для стабильного таймера
- chrome.notifications для уведомлений
- chrome.storage.local для хранения данных

---

## Ограничения

- Работает только с Steam Market
- Зависит от API priceoverview
- Требует разрешение на уведомления
