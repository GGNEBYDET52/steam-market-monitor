# Steam Market Monitor

![MIT License](https://img.shields.io/badge/License-MIT-green)
![Chrome Extension](https://img.shields.io/badge/Chrome%20Extension-v17.0-blue)

Расширение для Chrome (и Яндекс.Браузера) для мониторинга цен предметов на торговой площадке Steam.

---

## 🔎 Особенности

- Мониторинг нескольких предметов одновременно  
- Индивидуальные триггеры на повышение/понижение цены  
- Автоматические проверки с рандомным интервалом  
- Фоновый таймер через `chrome.alarms`  
- Системные уведомления при срабатывании  
- Открытие страницы предмета при событии  
- Подсветка, статус мониторинга и история последних проверок

---

## ➕ Установка

1. Скачайте или клонируйте репозиторий  
2. Откройте `chrome://extensions`  
3. Включите *Режим разработчика*  
4. Нажмите **Загрузить распакованное расширение**  
5. Выберите папку проекта

---

## 🧠 Использование

1. Перейдите во вкладку *Добавить*  
2. Вставьте ссылку предмета на Steam Market  
   > Например: `https://steamcommunity.com/market/listings/730/AK-47%20|%20Phantom%20Disruptor%20(Minimal%20Wear)`  
3. Укажите пороги и сохраните  
4. Сохраните интервал проверки  

---

## ⚙️ Конфигурация

- `minInterval` — минимальный интервал между проверками (сек)  
- `maxInterval` — максимальный интервал  
- `minChance` — шанс выбора минимального интервала
