# Steam Market Monitor

![Chrome Extension](https://img.shields.io/badge/Chrome%20Extension-v18.0-blue)
![MIT License](https://img.shields.io/badge/License-MIT-green)

Мониторинг цен предметов на торговой площадке Steam.

---

## 🔍 Описание

Chrome/Яндекс расширение для отслеживания изменения цен предметов в Steam Market с:

- Проверка цены ниже / выше
- Рандомный интервал между запросами
- Системные уведомления
- Открытие вкладки при срабатывании
- Подсветка при приближении к триггеру

---

## 🛠 Установка

1. Скачай или клонируй репозиторий
2. Открой `chrome://extensions`
3. Включи **Режим разработчика**
4. Нажми **Загрузить распакованное расширение**
5. Выбери корневую папку проекта

---

## 🚀 Как использовать

1. Перейди на вкладку **Добавить**
2. Вставь ссылку на предмет Steam Market
3. Укажи значения:
- Цена ниже
- Цена выше
4. Сохрани интервал
5. Перейди на **Мониторинг**

---

## ⚙️ Интервал проверки

| Параметр | Описание |
|----------|-----------|
| minInterval | Мин. интервал (сек) |
| maxInterval | Макс. интервал (сек) |
| minChance | Вероятность выбрать minInterval |
